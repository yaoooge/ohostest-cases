# 综合商城多设备 UI 适配任务

## 产品背景

这是一个具备首页、分类、购物车、个人中心、商品列表、商品详情、订单和积分商城等完整购物流程的综合商城。

当前商城以手机竖屏体验为基础，在折叠屏展开态和平板等更宽设备上仍沿用固定手机布局，导致页面空间利用不足、商品浏览效率偏低。请在保持现有购物功能和交互习惯的前提下，为商城补充多设备响应式 UI，使用户在手机、折叠屏和平板上都能获得适合当前窗口宽度的展示效果。

## 产品目标

1. 商城能够根据当前窗口宽度在 SM、MD、LG 三档布局间自然切换。
2. 窄屏保持原有手机体验，不因适配产生功能回退或横向溢出。
3. 折叠屏展开态提高内容密度，同时继续使用易于单手浏览的纵向页面结构。
4. 平板充分利用宽屏空间，通过多列、左右分栏和居中弹层提高浏览与操作效率。
5. 窗口宽度发生变化后，当前页面能够自动更新为对应布局，无需重新启动商城。

## 各断点产品表现

### 商城首页

| 展示区域 | SM | MD | LG |
| --- | --- | --- | --- |
| 页面背景 | 保持手机透明背景 | 与 SM 一致 | 使用适合宽屏内容卡片的灰色背景 |
| 搜索入口 | 搜索框位于标题下方，可随页面滚动收起 | 与 SM 一致 | 搜索框放在标题行右侧，宽度约 400vp |
| 首页横幅 | 宽高比 4:3 | 宽高比 2.5:1 | 宽高比 5:1 |
| 分类入口 | 横向排列并靠左，可横向浏览 | 与 SM 一致 | 在可用宽度内均匀分布 |
| 商品瀑布流 | 初始 2 列 | 初始 3 列 | 初始 5 列 |
| 双指缩放 | 不改变列数 | 可在 2–4 列间调整 | 可在 4–6 列间调整 |

三个断点必须使用同一张基础横幅图片，只改变图片容器的显示比例。不要增加或恢复平板专用首页图片。

所有商品卡片必须完整显示，不能超出容器，也不能因增列而遮挡标题、价格或操作信息。

### 商品详情和评价

商品详情在三档布局下都必须保留客服、购物车、加入购物车、立即购买、收藏、评价和商品介绍等原有能力。

## 体验约束

1. 保留首页、分类、购物车、个人中心四个主入口及其现有顺序。
2. 保留商品搜索、筛选、收藏、浏览记录、评价、加购、购买、订单和积分兑换流程。
3. 保留商品链接直达和订单快捷入口等已有外部进入方式。
4. 不改变现有商品数据、价格、库存、购物车计算和订单业务语义。
5. 所有页面在三个断点下都不得出现横向溢出、内容重叠、操作按钮被裁切或底部区域不可触达。
6. 列数变化后应保持商品阅读顺序稳定，滚动和点击行为符合用户预期。
7. 加载中、空状态和加载失败状态也要适应当前窗口宽度。

## 能力边界

本任务只包含多设备 UI 适配，不包含应用内分屏购物能力。商品详情在任何断点下都不应出现创建分屏或合并分屏的入口。

不要增加平板专用首页图片；首页在 SM、MD、LG 下只通过同一基础图片的 4:3、2.5:1、5:1 显示比例体现差异。

## 验收标准

1. 手机窄屏保持原有单列购物体验，首页横幅为 4:3，普通商品为 2 列。
2. 折叠屏展开态下，首页横幅为 2.5:1，普通商品为 3 列，分类和评价媒体正确增列。
3. 平板宽屏下，首页搜索框进入标题行，横幅为 5:1，商品流为 5 列。
4. 平板上的购物车、订单、秒杀、收藏和商品列表按要求展示双列。
5. 平板商品详情采用左右分栏，购买按钮尺寸稳定，评价内容正确增列。
6. 平板购物车金额明细以居中窄弹层展示。
7. 个人中心和积分商城在不同断点下符合上述排列和列数要求。
8. 窗口在不同宽度间变化后，页面能自动切换布局。
9. 所有原有购物流程在三个断点下均可正常使用。
10. 工程中不包含应用内分屏购物入口或行为。
