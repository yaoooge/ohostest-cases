# 综合商城分屏购物能力任务

## 产品背景

这是一个具备完整商品浏览和购买流程的综合商城。用户可以从首页或商品链接进入商品详情，查看商品图片、价格、规格和评价，并继续加购或购买。

当前商城一次只能使用一个购物窗口。在支持分屏的折叠屏和平板上，用户希望保留当前商品的同时打开第二个商城窗口，以便对照商品信息、继续浏览其他商品或处理购物车，并在需要时将两个窗口重新合并。

请为商城补充分屏购物能力，同时保持基础工程现有的固定单列页面布局和全部购物功能。

## 产品目标

1. 在支持分屏的中宽和宽屏设备上，用户可从商品详情发起分屏购物。
2. 分屏创建后，主窗口和分屏窗口都具有完整、可独立操作的商城页面上下文。
3. 用户在任一窗口中的搜索、浏览、加购、购物车和页面返回操作只影响当前窗口。
4. 用户可以从任一窗口结束分屏，并获得清晰、连续的页面结果。
5. 用户通过系统方式关闭分屏窗口后，主窗口能够自动恢复正常状态。

## 用户旅程

### 进入商品详情

1. 用户可以从商城首页进入商品详情。
2. 用户也可以通过现有商品链接直接进入指定商品详情。
3. 在不支持分屏的窄手机窗口中，不显示分屏入口。
4. 在支持分屏的折叠屏展开态和平板窗口中，商品详情显示分屏入口。

### 启动分屏

1. 用户点击分屏入口后，当前商城成为主窗口。
2. 系统在另一侧创建分屏窗口。
3. 分屏窗口打开时应显示与主窗口相同的商品详情，而不是商城首页、空白页或加载错误页。
4. 两个窗口都保留商品图片、价格、规格、评价、客服、购物车、加入购物车和立即购买能力。
5. 分屏建立后，两个窗口都显示合并入口。即使单个窗口因分屏而变窄，合并入口也不能消失。

### 分屏状态下继续购物

1. 用户可聚焦任一窗口并独立浏览。
2. 用户在分屏窗口进入另一件商品、购物车或其他商城页面时，主窗口当前页面不应被同步替换。
3. 轻提示、弹层、返回操作和后续导航应出现在用户当前正在操作的窗口中。
4. 两个窗口共享正常的商城业务数据。例如在一个窗口加入购物车后，另一个窗口后续查看购物车时能够看到一致的业务结果。

### 从分屏窗口合并

1. 用户在分屏窗口点击合并后，分屏窗口关闭。
2. 主窗口恢复全屏。
3. 主窗口继续保留合并前原本显示的商品详情和页面历史。
4. 主窗口恢复后可再次发起分屏。

### 从主窗口合并

1. 用户可先在分屏窗口继续浏览另一件商品、购物车或其他页面。
2. 用户回到主窗口点击合并后，分屏窗口关闭。
3. 主窗口恢复全屏，并接管分屏窗口合并前正在浏览的页面及其返回历史。
4. 用户可以从接管后的页面继续购物，不应跳回商城首页或丢失当前商品。

### 系统关闭分屏窗口

1. 用户通过系统窗口控制关闭分屏窗口时，主窗口自动恢复全屏。
2. 商城应清除已结束的分屏状态。
3. 主窗口继续正常响应点击、返回、弹层和页面跳转。
4. 商品详情重新显示可用的分屏入口，允许用户再次发起分屏。

## 窗口和状态要求

| 场景 | 主窗口 | 分屏窗口 | 用户结果 |
| --- | --- | --- | --- |
| 分屏前 | 全屏展示商品详情 | 不存在 | 正常单窗口购物 |
| 分屏建立 | 位于主区域 | 位于次区域 | 两侧显示相同商品详情 |
| 分屏浏览 | 保持独立页面历史 | 可独立浏览和购物 | 当前窗口操作不串到另一窗口 |
| 从分屏窗口合并 | 恢复全屏并保留原页面 | 关闭 | 用户回到主窗口原页面 |
| 从主窗口合并 | 恢复全屏并接管分屏页面 | 关闭 | 用户继续分屏窗口中的浏览进度 |
| 系统关闭分屏窗口 | 恢复全屏 | 销毁 | 状态复位，可再次分屏 |

## 体验约束

1. 分屏启动、切换焦点、合并和异常关闭过程中不能出现空白页或明显闪退。
2. 用户快速重复点击分屏或合并入口时，不能创建重复分屏窗口或产生无法恢复的状态。
3. 分屏启动失败时，主窗口继续正常使用，当前商品和购物流程不能丢失。
4. 分屏结束后不能残留错误的合并入口、失效窗口状态或无法点击的页面。
5. 商品链接直达、首页进入详情、购物车和返回导航在单窗口及分屏状态下都必须正常工作。
6. 分屏窗口关闭后再次创建分屏，行为应与首次创建一致。

## 能力边界

本任务只包含分屏购物能力，不包含多设备响应式 UI 改造。

即使在折叠屏展开态或平板宽窗口中，首页、商品列表、购物车、个人中心和商品详情仍保持基础工程的固定手机布局；商品详情继续采用固定单列结构，不增加宽屏左右分栏，也不增加多断点列数变化或商品流缩放能力。

不要增加或恢复平板专用首页图片。

## 验收标准

1. 窄手机窗口不显示分屏入口。
2. 支持分屏的折叠屏和平板商品详情显示分屏入口。
3. 发起分屏后同时存在主窗口和分屏窗口，且窗口位置和角色正确。
4. 分屏窗口显示与主窗口相同的商品详情。
5. 两个窗口都能独立完成浏览、返回、加购和进入购物车等操作。
6. 分屏状态下两个窗口都能看到合并入口。
7. 从分屏窗口合并后，主窗口保留原页面并恢复全屏。
8. 从主窗口合并后，主窗口接管分屏窗口最新页面和返回历史。
9. 系统关闭分屏窗口后，主窗口自动恢复并可再次发起分屏。
10. 宽屏状态下仍保持固定单列页面，不出现响应式多列或左右分栏。
