# 综合商城分屏购物能力任务

## 产品背景

这是一个具备完整商品浏览和购买流程的综合商城。用户可以从首页或商品链接进入商品详情，查看商品图片、价格、规格和评价，并继续加购或购买。

当前商城一次只能使用一个购物窗口。在支持分屏的折叠屏和平板上，用户希望保留当前商品的同时打开第二个商城窗口，以便对照商品信息、继续浏览其他商品或处理购物车，并在需要时将两个窗口重新合并。

请为商城补充分屏购物能力，同时保持基础工程现有的固定单列页面布局和全部购物功能。

## 用户旅程

### 启动分屏

1. 用户在商品详情页中点击分屏入口后，当前商城成为主窗口。
2. 系统在另一侧创建分屏窗口。
3. 分屏窗口打开时应显示与主窗口相同的商品详情。
4. 两个窗口都保留商品图片、价格、规格、评价、客服、购物车、加入购物车和立即购买能力。
5. 分屏建立后，两个窗口都显示合并入口。

### 分屏状态下继续购物

1. 用户可聚焦任一窗口并独立浏览。
2. 用户在分屏窗口进入另一件商品、购物车或其他商城页面时，主窗口当前页面不应被同步替换。
3. 轻提示、弹层、返回操作和后续导航应出现在用户当前正在操作的窗口中。
4. 两个窗口共享正常的商城业务数据。例如在一个窗口加入购物车后，另一个窗口后续查看购物车时能够看到一致的业务结果。

### 从分屏窗口合并

1. 用户在分屏窗口点击合并后，分屏窗口关闭。
2. 主窗口恢复全屏。
3. 主窗口继续保留合并前原本显示的商品详情和页面历史。
4. 主窗口恢复后可再次发起分屏。

### 从主窗口合并

1. 用户可先在分屏窗口继续浏览另一件商品、购物车或其他页面。
2. 用户回到主窗口点击合并后，分屏窗口关闭。
3. 主窗口恢复全屏，并接管分屏窗口合并前正在浏览的页面及其返回历史。
4. 用户可以从接管后的页面继续购物，不应跳回商城首页或丢失当前商品。

### 系统关闭分屏窗口

1. 用户通过系统窗口控制关闭分屏窗口时，主窗口自动恢复全屏。
2. 商城应清除已结束的分屏状态。
3. 主窗口继续正常响应点击、返回、弹层和页面跳转。
4. 商品详情重新显示可用的分屏入口，允许用户再次发起分屏。

## 窗口和状态要求

| 场景 | 主窗口 | 分屏窗口 | 用户结果 |
| --- | --- | --- | --- |
| 分屏前 | 全屏展示商品详情 | 不存在 | 正常单窗口购物 |
| 分屏建立 | 位于主区域 | 位于次区域 | 两侧显示相同商品详情 |
| 分屏浏览 | 保持独立页面历史 | 可独立浏览和购物 | 当前窗口操作不串到另一窗口 |
| 从分屏窗口合并 | 恢复全屏并保留原页面 | 关闭 | 用户回到主窗口原页面 |
| 从主窗口合并 | 恢复全屏并接管分屏页面 | 关闭 | 用户继续分屏窗口中的浏览进度 |
| 系统关闭分屏窗口 | 恢复全屏 | 销毁 | 状态复位，可再次分屏 |
